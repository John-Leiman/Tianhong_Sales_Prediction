一、建模方法

本项目对110门店所有有效SKU的每日销售成本进行预测。由于品类中既有长期在售商品，也有新上架商品，我们按历史数据长度将SKU划分为两个分段，分别匹配最适合的模型族。

112天门槛来自交叉验证设置：28天预测步长 × （3折 + 1个训练块）= 最少112天。

1.2 · 参与评估的模型

单SKU模型  每条序列独立拟合：

  • 季节性朴素法 — 重复最后7天的销售周期，作为基准。
  • Holt-Winters指数平滑 — 加法趋势 + 周季节性，数据不足时逐步回退至简单平滑或朴素法。
  • Prophet — 加法分解模型，含周季节性。

全局ML模型  跨所有SKU共享一个模型：

  • 岭回归（标准化）
  • HistGradientBoosting
  • 随机森林
  • LightGBM  最优

1.3 · 交叉验证策略

模型选择采用滚动时间序列交叉验证（3折，每折预测步长28天）。主要评估指标为MAE（绝对误差均值，单位：元）；sMAPE作为辅助指标，仅在实际销售额不为零的天数上计算，以避免零值填充导致sMAPE虚高至200%上限。

1.4 · 特征工程 — LLM辅助设计

全局模型每个SKU-日使用22个特征。数值与时间特征为通用做法；促销特征的构建需要理解中文自由文本标签，这正是引入LLM的环节：

促销类型的语义聚类。 原始promotional_data.csv中包含多种中文促销类型标签（如 组合促销、线上组合促销、满额促销、 库区折率单折扣、超市线上促销等）。LLM读取完整标签集后， 将其归类为四个业务语义清晰的二值标志——组合促销、满额促销、 库区折扣和线上促销——将嘈杂的类别字段压缩为紧凑、可解释的特征空间。 LLM还提出了衍生信号：discount_depth（折扣深度）、 days_since_promo（距上次促销天数）和 rolling_promo_7（过去7天促销频次）。

三、局限性与数据质量问题

以下几类数据质量问题制约了预测精度，建议在正式投入使用前加以解决。

3.1 · 销售成本（COGS）存在负值

在320万条记录中，共有 4,744行（0.148%） 涉及 3,435个SKU 的当天全部销售成本金额为负值，最极端的单条记录为 −¥108,593。

负值COGS在ERP系统中属于正常业务事件，包括：退货与逆向物流导致的成本冲销、供应商返利或采购信用、手工更正录入，以及门店间转移时的成本分摊。但预测目标理论上应为非负值，这些记录向模型注入了矛盾信号——模型学会了"某些天成本可为负"，而预测截断至零后，对退货率高的SKU会产生系统性的低估偏差。

  • 建议将退货/信用行与净销售行分开汇总。
  • 对毛销售成本与退货率分别独立建模后合并。
  • 至少应对负值天数加以标记，并从交叉验证误差计算中排除。

3.2 · 历史数据短且稀疏不均

11,203个SKU（占全量38%） 的历史数据不足180天。 历史跨度分位数：P10 = 19天 · P25 = 86天 · 中位数 = 282天。 另有 9,076个SKU 的历史数据低于112天的最低门槛，无法生成预测。

短历史数据对基于滞后特征的模型造成级联破坏：

  • 仅有30天历史的SKU，其28天滞后特征在93%的训练行中为缺失值，28天滚动均值也无法计算。LightGBM可原生处理缺失值；而岭回归和随机森林接收到零值填充的滞后特征，会扭曲学习到的关系。
  • Holt-Winters需要至少两个完整季节周期（对应周期=7时为14天），不足时逐步回退至更简单的平滑或朴素法。
  • Prophet在样本量低于约90个观测点时预测可靠性大幅下降。

建议： 基于商品属性建立冷启动先验；对同品类SKU进行层次聚合，为新品借用信号。

3.3 · 零销售报告方式不一致，含义模糊

原始数据中有 44,804行（1.4%） 的销售成本金额精确等于0； 另有数量不明的SKU-日数据完全缺失（源文件中为空行）， 被 fill_daily() 日历重索引步骤统一填充为0， 目前无法与真实零值区分。

一个零值（无论记录为 0 还是缺失空行）可能代表以下任意一种情况：

  • 真实零需求 — 商品有货，但当天无人购买。
  • 缺货 — 商品无货；潜在需求为正，但无法被观测。
  • 门店关闭 / 节假日 — 当天无任何交易。
  • 数据传输中断 — 记录未上报，空缺被当作零处理。

由于编码方式不一致（有时报 0，有时为空行），上述情况目前无法区分。汇总sMAPE在全天口径下高达137%，但限定在非零实际天数后降至65%，证明是零值膨胀而非模型误差驱动了表观误差率。

建议： 引入缺货/门店关闭标志；采用两阶段建模——先预测P(销售额>0)，再预测E[销售额 | 销售额>0]；并分别对零值天与非零值天报告预测精度。

3.4 · 预测变量覆盖面有限

当前模型仅利用销售历史和稀疏的促销标志。缺失但价值较高的预测变量包括：真实货架价格/竞品价格及价格弹性；商品属性（品类、品牌、保质期——目前仅以SKU整数编码作为类别代理）；以及门店与外部因素（仅有单店数据，缺乏天气、本地活动或更丰富的节假日日历）。折扣深度特征在实践中也较弱——促销日的平均折扣深度仅为 0.057，主要为库区折率调整，而非面向消费者的实质性降价。
